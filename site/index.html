Core Features

Everything you need for seamless multi-monitor window management.

🖥️

Per-Monitor Spaces

Switch spaces on one display without affecting the others. Create new spaces with + or remove with ×; windows automatically migrate to the neighboring space.

🪟

macOS-Style Mission Control

Press Win+Tab or click the tray icon for a smooth, GPU-accelerated Exposé overlay with 60+ FPS live DWM window thumbnails and top spaces bar.

🔲

Hyprland-Like Dynamic Tiling

Turn on automatic dwindle tiling anytime with Ctrl+Alt+Shift+T. Supports configurable gaps, shadow margins, border resizing, and float rules.

🖐️

Drag-and-Drop Relocation

In Mission Control, drag any window thumbnail onto a space card in the top bar to move it across spaces, or drop it on + to create a new space.

📌

Sticky Windows

Pin a window (Ctrl+Alt+Shift+P or the pin button in Mission Control) so it stays visible across all spaces on that monitor. Ideal for Slack, Spotify, or notes.

💼

Layout Save & Restore

Capture your multi-monitor window layout to JSON and restore it on startup or on demand. Spaces survive monitor disconnects, sleep, and RDP sessions.

🎨

Windows 11 Native UI

Hand-drawn Settings window with real Mica backdrop, fluent acrylic tray context menu with Segoe Fluent Icons, and active space tray badges.

🛡️

Safe & Zero-Cost Rust

Built with raw Win32 FFI (windows-sys) with no runtimes. Includes an emergency uncloak script (dev recover) so windows are never stranded.

How to Use WinSpaces

Get up and running in 3 simple steps.

1

Install & Launch

Run the per-user installer (no admin required) or copy winspaces.exe with an empty settings.json for portable mode. WinSpaces runs in the system tray.

2

Switch & Move

Press Alt + 1..9 to switch spaces on the current monitor. Press Ctrl + Alt + 1..9 to send the active window to that space.

3

Mission Control

Press Win+Tab or click the tray icon. See all open windows live, drag them between space cards, or press P to pin a sticky window.

Command Line & Configuration

Control the running daemon from scripts or shortcuts via IPC.

winspaces.exe --settings Opens the native Windows 11 Settings window
winspaces.exe --mission-control Toggles Mission Control (pin as taskbar shortcut)
winspaces.exe --tiling-toggle Toggles dynamic tiling layout
winspaces.exe --restart Restarts the daemon and reloads settings cleanly
winspaces.exe --exit Gracefully stops daemon, uncloaking all windows first
winspaces.exe --enable-elevation Enables admin task to manage elevated / admin windows
Configuration location: Plain JSON in %LOCALAPPDATA%\WinSpaces\settings.json (or next to the .exe in portable mode).

Frequently Asked Questions

What happens if WinSpaces crashes while windows are hidden?

Windows on inactive spaces are hidden via DWM cloaking. Simply relaunch WinSpaces to reclaim them, or run dev recover (or scripts/recover-windows.ps1) to instantly uncloak every window.

Can it manage windows running as Administrator?

Yes. Windows UIPI prevents standard processes from manipulating elevated windows. Turn on Run with Administrator Privileges in Settings or run winspaces.exe --enable-elevation.

How does Portable Mode work?

Create an empty settings.json file next to winspaces.exe. All settings, layouts, and logs will be kept right there in that folder without touching %LOCALAPPDATA%.
