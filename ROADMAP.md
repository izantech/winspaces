# WinSpaces Roadmap

Prioritized from the August 2026 full-codebase review and subsequent cloaking research. Ordered by value against effort — items are expected to be tackled roughly top to bottom.

## 1. Purchase a production code-signing certificate (user action)

The distribution pipeline is built (`docs/distribution.md`): Inno installer via `dev dist`, signing plumbing verified with a dev certificate, tag-triggered draft releases in CI, manual update check in the tray. The one thing code cannot do is the OV/EV certificate purchase (identity verification + payment). Until then, SmartScreen warns on downloads.

---

Settled decisions that should not be revisited: tray left-click is an instant Mission Control toggle (no double-click action, no delay timer); window hiding is `DWMWA_CLOAK` (mode A) and the ImmersiveShell `SetCloak` with a `SW_FORCEMINIMIZE` fallback (mode B) — forced minimize as the primary mode-B mechanism was abandoned because apps observe it and Chromium white-flashes on every restore (`docs/dwm.md` §5.2/§5.4/§5.6); window eligibility is structural — Alt-Tab-style owner-chain/style/class/cloak rules with a pure tested `is_eligible` (`docs/mission-control.md` §5) — never substring or localized title matching; the daemon ships **non-elevated** with an opt-in elevated scheduled task for power users (`docs/ipc-and-config.md` §5) — never "always run as admin"; the settings UI is native Rust inside the daemon binary, opened as `winspaces.exe --settings` in its own process (`docs/settings-ui.md`) — never a second toolchain or UI framework; settings colors come only from `settings_ui/theme.rs` palette tokens — no ARGB literals outside it; and the UI-local theme preference lives in `HKCU\Software\WinSpaces\GuiTheme`, never in the daemon's `settings.json` contract. Mission Control transitions are DWM thumbnail + GDI tweens on a `WM_TIMER` (`docs/mission-control.md` §6) — never DirectComposition/Direct2D/WinRT (none of the three are present in `windows-sys` 0.59's feature set; only `Win32_Graphics_{Dwm,Gdi,GdiPlus,Hlsl,OpenGL,Printing}` exist) and never a `WS_EX_LAYERED` whole-overlay fade (DWM composites thumbnails into the destination window and they do not fade with layered-window alpha, and `WS_EX_LAYERED` voids the `DWMSBT_ACRYLIC` backdrop). The desktop/space-switch animation *outside* Mission Control (a full-screen transition on every `Alt+`digit switch, independent of the overlay) was investigated and dropped: incoming windows are cloaked and uncapturable, a full-monitor `BitBlt` taxes every switch, DRM content captures black, and spreading `switch_desktop` across frames would make mid-transition cloak state crash-observable.
